# Day 18 – Projects

**Core idea:** Work one narrow idea, place, or theme for the entire session so the pictures begin to form a coherent set.

## Why this exercise matters
Isolated exercises produce isolated pictures. Projects create coherence, deeper seeing, and the possibility of a real body of work. This day is the bridge from practice exercises to self-directed photography. Most lasting street work is project-based.

## Shooting brief
Choose one narrow constraint (a single block, a type of storefront, people carrying specific things, a particular light condition, a recurring gesture, one intersection, one kind of interaction). Shoot only inside that constraint. Aim for a coherent set of 8–12 frames that could start a longer project. Write a one-sentence project statement in your notes. Volume 40–70.

## Technical & practical guidance
- Settings: Keep approach and look consistent across the set.
- Focusing, stance, light, distance: Whatever the project demands, held consistent so the pictures sit together.

Consistency of method strengthens the set more than variety.
Mix of candid and any approached portraits that fit the project idea.

## Common failure modes
- Project idea too broad to create coherence.
- Inconsistent approach so the set does not hold together.
- Abandoning the constraint when the street offers something tempting outside it.
- Ending with a pile of related but not coherent pictures.

## Good vs excellent
**Good:** A set of related pictures.  
**Excellent:** The set has internal consistency of seeing, light, and approach. The strongest frames could continue as a real body of work and the project statement is clear and true.
