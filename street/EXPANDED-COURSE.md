# Expanded 20-Day Street Photography Course

Rewritten for stronger teaching. Each lesson is self-contained (5–15 min read). Technical guidance targets real street conditions and APS-C gear (Sony ZV-E10 II + 24-50mm f/2.8 G → ~36–75mm equivalent).

**Live site:** https://rcityphotography.com/street

Full lesson text lives in each Day folder README (and is summarized on the site).
